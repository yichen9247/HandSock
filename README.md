# [YunChat](https://github.com/yichen9247/YunChat) &middot; ![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg) ![author](https://img.shields.io/badge/author-Hua-blue.svg) ![Node.js Version](https://img.shields.io/badge/node.js-16.20.2-blue.svg)

## 📦 项目介绍

YunChat是一款有趣且开源的聊天应用，基于 Springboot、Vite、TypeScript、Redis、Socket.IO、Kotlin等技术开发。

## 🛠 技术选型

### 核心选型
- **MySQL** - 关系型数据库
- **Socket.IO** - 实时通信库

### 后端选型
- **Redis** - 高性能缓存
- **Spring Boot** - Java Web框架
- **Mybatis Plus** - Mybatis的增强工具

### 前端选型
- **Vite** - 下一代前端构建工具
- **Vue Router** - Vue3的路由库
- **Vue3** - 渐进式JavaScript框架
- **Sweetalert2** - 一个优雅的弹窗库
- **Element Plus** - 基于Vue3的组件库
- **TypeScript** - 类型安全的JavaScript超集

### 移动端选型
- **Kotlin** - 现代Android开发语言
- **Android Compose** - 声明式安卓框架
